# 김일현 포트폴리오 기획서

## 배경

신입 백엔드 개발자 직무에 지원하는 김일현을 소개하는 개인 포트폴리오다. 소개글과 사진, 기술 스택의 숙련도, 팀 프로젝트에서 맡은 역할을 한곳에 담는다.

## 문제

기술 이름만 나열하면 어떤 기술에 더 익숙한지 비교하기 어렵다. 팀 프로젝트의 서비스 소개만으로는 지원자가 무엇을 맡았고 어떤 방식으로 구현했는지 파악하기 어렵다.

## 목표 이용자

1. **개발팀 면접관**은 프로젝트에서 김일현이 직접 맡은 역할, 사용한 기술과 그 적용 방식, GitHub 코드를 살펴본다.
2. **인사 담당자**는 김일현이 지원하는 직무와 주요 기술, 프로젝트의 성격을 짧은 시간에 파악한다.

## 컨셉

“부족한 부분을 스스로 찾아 공부하고, 오류의 원인을 분석해 해결하는 것을 좋아하는 신입 백엔드 개발자 김일현입니다.”

첫 화면에 사진과 짧은 소개글을 배치한다. 본문은 제목과 여백으로 구분하고, 차분한 바탕에 강조색 한 가지를 사용해 핵심 역할과 기술 점수에 시선이 가도록 한다. 프로젝트 상세에서는 본인이 맡은 역할과 구현 내용을 중심으로 소개한다.

## 화면

### 메인

상단에 김일현의 사진과 소개글을 배치한다. 이어서 기술 숙련도와 프로젝트 카드를 보여준다.

기술 숙련도는 **5점 만점의 자기평가**이며 **0.5점 단위**로 표시한다. 분야별로 묶고, 같은 길이의 막대와 숫자 점수를 나란히 표시해 비교할 수 있게 한다.

| 분야 | 기술별 숙련도 |
| --- | --- |
| 언어 | Java 4점, JavaScript 4점 |
| 백엔드 | Spring Boot 3.5점, Spring MVC 5점, MyBatis 4점, JWT 인증 3점 |
| 프런트엔드 | React 3점, JSP 4점, HTML 4점, CSS 3점, Ajax 3.5점 |
| 데이터베이스 | MySQL 4점 |
| 프로젝트 외 실습 | Oracle DB 4점 |
| 실시간 통신 | WebSocket 3.5점, STOMP 3.5점 |
| 협업 도구 | Git 4점, GitHub 3.5점, Notion 3.5점, Slack 3점 |

프로젝트 카드는 모아(Moa)와 쉽코딩(EasyCoding)으로 구성한다. 각 카드에 프로젝트 이름, 한 줄 소개, 본인이 맡은 주요 역할을 담고 해당 프로젝트 상세 페이지로 연결한다.

### 프로젝트 상세

프로젝트의 목적, 기간과 팀 규모, 사용 기술, 본인이 맡은 역할과 주요 구현 내용, GitHub 저장소 링크를 담는다.

- **모아(Moa)**는 지역 기반 모임 서비스다. 팀장으로서의 개발 일정·이슈 관리와 기능 통합, 계모임의 회비·공동자금 관리, 토스페이먼츠 가상계좌 발급 API 연동, WebSocket과 STOMP 기반 채팅 구현을 소개한다. [모아 GitHub 저장소](https://github.com/siiiha/final_project_moa)
- **쉽코딩(EasyCoding)**은 개발 문제 풀이와 학습 기록을 제공하는 서비스다. 커뮤니티 이미지 업로드 구현과 JWT 기반 인증의 반복 처리 횟수 및 처리 시간을 줄인 작업을 소개한다. [쉽코딩 GitHub 저장소](https://github.com/Kim-ilhyeon/semi_project-easycoding)

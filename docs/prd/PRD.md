# 김일현 포트폴리오 PRD

## 기능 명세

### 필수

1. **첫 화면** — 이름, 한 줄 소개, 사용자가 첨부한 프로필 사진을 보여준다.
2. **소개·기술 스택** — 신입 백엔드 개발자로서의 학습 태도와 오류 해결에 대한 관심을 소개한다. 기술은 분야별로 묶고, 숙련도를 5점 만점의 자기평가로 표시한다. 0.5점 단위의 숫자와 동일한 척도의 막대를 함께 보여준다.
3. **프로젝트 카드와 상세 페이지** — 모아와 쉽코딩을 카드로 보여주고 각각의 상세 페이지로 연결한다. 상세 페이지에는 본인이 맡은 역할과 구현 내용, 프로젝트별 GitHub 저장소 링크와 개인 블로그 링크를 함께 표시한다.
4. **연락 링크** — 메인 화면에 개인 GitHub 프로필, 개인 블로그, 공개용 개발 이메일 링크를 제공한다.
5. **모바일 화면과 사이트 메타데이터** — 메인과 프로젝트 상세를 모바일 화면에서도 읽을 수 있게 구성하고, 사이트 제목과 설명을 메타데이터로 제공한다.

### 추후 반영

- 다크 모드
- 사이트 내 블로그
- 방명록(DB 필요)
- 다국어
- 방문자 통계

## 완료 기준

1. **첫 화면** — 메인을 열면 김일현의 이름, 한 줄 소개, 첨부한 프로필 사진이 보인다.
2. **소개·기술 스택** — 소개글에 스스로 부족한 부분을 공부하고 오류를 분석해 해결하는 데 관심이 있다는 내용이 보인다. 기술 19개가 분야별로 표시되고, 5점 만점의 자기평가라는 안내가 보인다. Spring MVC는 5점으로 막대가 가득 차고 Spring Boot는 3.5점으로 전체 길이의 70%가 채워진다.
3. **프로젝트 카드와 상세 페이지** — 메인에 모아와 쉽코딩 카드가 표시되고, 모아 카드를 선택하면 `/project/moa`, 쉽코딩 카드를 선택하면 `/project/easycoding`이 열린다. 상세 페이지에서 목적, 기간, 팀 규모, 사용 기술, 본인의 역할과 구현 내용을 읽을 수 있다. GitHub 링크는 해당 프로젝트 저장소로, 블로그 링크는 개인 블로그로 이동한다.
4. **연락 링크** — 메인에서 개인 GitHub, 블로그, 공개용 개발 이메일 링크가 보인다. GitHub와 블로그 링크는 각 페이지를 열고, 이메일 링크를 선택하면 기기에 설정된 메일 앱에서 공개용 개발 이메일이 받는 사람에 입력된다.
5. **모바일 화면과 사이트 메타데이터** — 브라우저를 모바일 너비로 줄여도 메인과 상세 화면의 콘텐츠가 가로 스크롤 없이 보이고 링크를 선택할 수 있다. 브라우저 탭에 사이트 제목이 표시되고, 개발자 도구에서 사이트 설명 메타 태그를 확인할 수 있다.

## 기술 방식

- Next.js(App Router)로 메인과 프로젝트 상세 페이지를 구성한다.
- TypeScript strict 모드로 데이터와 화면의 타입을 정의한다.
- Tailwind CSS로 화면과 반응형 레이아웃을 구성한다.
- 프로필 사진은 `next/image`로 표시하고 한글 대체 텍스트를 제공한다.
- 사이트 제목과 설명은 App Router의 메타데이터로 설정한다.
- 포트폴리오 데이터는 `src/data/profile.ts`에서 관리한다. DB와 로그인은 사용하지 않는다.

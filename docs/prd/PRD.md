# 김일현 포트폴리오 PRD

## 기능 명세

### 필수

1. **첫 화면과 숫자 요약** — 이름, 기획서의 한 줄 소개, 첨부한 프로필 사진을 보여준다. 바로 아래에 팀 프로젝트, 수료한 개발 교육과정, 사용 기술 스택 개수를 표시한다.
2. **활동·수상 이력과 기술 스택** — 활동과 수상 이력을 날짜순으로 보여준다. 기술은 분야별로 묶고, 숙련도를 5점 만점의 자기평가로 표시한다. 0.5점 단위의 숫자와 동일한 척도의 막대를 함께 보여준다.
3. **프로젝트 필터·카드·상세 페이지** — 전체, 팀 프로젝트, 개인 프로젝트, KH 정보교육원 필터를 제공한다. 처음에는 전체를 보여주며, 필터 선택에 따라 해당 카드만 표시한다. 카드를 선택하면 상세 페이지에서 본인이 맡은 역할과 구현 내용, 프로젝트별 GitHub 저장소 링크와 개인 블로그 링크를 확인할 수 있다.
4. **연락 링크** — 메인 화면에 개인 GitHub 프로필, 개인 블로그, 공개용 개발 이메일 링크를 제공한다.
5. **모바일 화면과 사이트 메타데이터** — 메인과 프로젝트 상세를 모바일 화면에서도 읽을 수 있게 구성하고, 사이트 제목과 설명을 메타데이터로 제공한다.

### 추후 반영

- 다크 모드
- 사이트 내 블로그
- 방명록(DB 필요)
- 다국어
- 방문자 통계

## 화면별 요소

**디자인 방향** — 메인과 프로젝트 상세의 공통 배경은 밝은 웜 그레이(`#F3F2ED`)로 한다. 시스템 라이트·다크 모드에서 같은 공통 배경색을 유지한다. 본문에 강조색 한 가지와 넉넉한 여백을 사용하고, 숫자 요약과 하단 연락 영역은 어두운 배경으로 대비를 준다.

| 화면 | 요소 |
| --- | --- |
| 메인 | 소개 → 숫자 요약 → 프로젝트 필터 및 카드 → 활동·수상 이력 → 기술 스택 → 연락 순서로 세로 배치한다. 넓은 화면에서는 소개를 왼쪽에, 사진을 오른쪽에 둔다. 모바일에서는 소개와 사진을 세로로 배치한다. 하단 연락 영역에는 개인 GitHub·블로그·공개용 개발 이메일 링크를 표시한다. |
| 프로젝트 상세 | 프로젝트 이름과 목적, 기간과 팀 규모, 사용 기술, 본인이 맡은 역할과 주요 구현 내용, 프로젝트별 GitHub 저장소 링크, 개인 블로그 링크 |
| 공통 | 모바일 화면에 맞는 레이아웃, 사이트 제목과 설명 메타데이터 |

프로젝트 제목과 카드 목록 사이에 필터를 배치한다. 카드에는 프로젝트 이름, 한 줄 소개, 본인이 맡은 주요 역할을 표시한다. 선택한 분류에 프로젝트가 없으면 비어 있음을 안내한다.

## 완료 기준

1. **첫 화면과 숫자 요약** — 메인을 열면 김일현의 이름, 한 줄 소개, 첨부한 프로필 사진이 보인다. 넓은 화면에서는 소개가 왼쪽, 사진이 오른쪽에 보이고, 그 아래 숫자 요약에 팀 프로젝트 2개, 개발 교육과정 2개 수료, 사용 기술 스택 19개가 표시된다.
2. **활동·수상 이력과 기술 스택** — 활동 5건과 수상 2건이 각각 날짜 또는 시작일 순서로 보인다. 기술 19개가 분야별로 표시되고, 5점 만점의 자기평가라는 안내가 보인다. Spring MVC는 5점으로 막대가 가득 차고 Spring Boot는 3.5점으로 전체 길이의 70%가 채워진다.
3. **프로젝트 필터·카드·상세 페이지** — 프로젝트 목록 위에 전체, 팀 프로젝트, 개인 프로젝트, KH 정보교육원 필터가 보인다. 전체와 팀 프로젝트에서는 모아·쉽코딩 카드가 보이고, 개인 프로젝트에서는 빈 목록 안내가 표시된다. KH 정보교육원 필터에서는 해당 분류에 등록된 카드만 보이며, 등록된 카드가 없으면 빈 목록 안내가 표시된다. 모아 카드를 선택하면 `/project/moa`, 쉽코딩 카드를 선택하면 `/project/easycoding`이 열린다. 상세 페이지에서 목적, 기간, 팀 규모, 사용 기술, 본인의 역할과 구현 내용을 읽을 수 있고, GitHub와 블로그 링크는 각각 해당 저장소와 개인 블로그로 이동한다.
4. **연락 링크** — 메인에서 개인 GitHub, 블로그, 공개용 개발 이메일 링크가 보인다. GitHub와 블로그 링크는 각 페이지를 열고, 이메일 링크를 선택하면 기기에 설정된 메일 앱에서 공개용 개발 이메일이 받는 사람에 입력된다.
5. **모바일 화면과 사이트 메타데이터** — 브라우저를 모바일 너비로 줄여도 메인과 상세 화면의 콘텐츠가 가로 스크롤 없이 보이고 링크를 선택할 수 있다. 브라우저 탭에 사이트 제목이 표시되고, 개발자 도구에서 사이트 설명 메타 태그를 확인할 수 있다.

**공통 배경 확인** — 시스템 라이트 모드와 다크 모드에서 메인과 프로젝트 상세의 공통 배경이 모두 `#F3F2ED`로 표시된다.

## 기술 방식

- Next.js(App Router)로 메인과 프로젝트 상세 페이지를 구성한다.
- TypeScript strict 모드로 데이터와 화면의 타입을 정의한다.
- Tailwind CSS로 화면과 반응형 레이아웃을 구성한다.
- 프로필 사진은 `next/image`로 표시하고 한글 대체 텍스트를 제공한다.
- 사이트 제목과 설명은 App Router의 메타데이터로 설정한다.
- 포트폴리오 데이터는 `src/data/profile.ts`에서 관리한다. DB와 로그인은 사용하지 않는다.

# 개발 서버에서 배경색 변경이 반영되지 않음

## 문제

태스크 1에서 공통 배경을 밝은 웜 그레이(`#F3F2ED`)로 설정했지만, Windows 다크 모드를 사용하는 Chrome에서 `http://localhost:3000`의 본문이 검게 표시됐다. 브라우저 탭 제목은 새 제목인 `김일현 Portfolio`로 바뀌어 있었 개발 서버 재시작과 강력 새로고침만으로는 배경색이 바뀌지 않았다.

## 원인을 발견한 과정

1. `src/app/globals.css`에서 `--background: #F3F2ED`와 `color-scheme: light`가 설정되어 있는지 확인했다.
2. 프로덕션 빌드의 CSS에서도 같은 배경색을 확인했다.
3. `localhost:3000`의 개발자도구로 HTML에 연결된 CSS를 서버에서 직접 받아 비교했다. 응답에는 이전 배경색 `#FFFFFF`와 `@media (prefers-color-scheme: dark)`에서 배경을 `#0A0A0A`로 덮어쓰는 규칙이 남아 있었다.

## 원인

개발 서버가 이전 CSS를 제공했고, Windows의 다크 모드에서 그 CSS의 어두운 배경 규칙이 적용됐다. 서버 응답에서 이전 CSS가 제공된 사실은 확인했다. 개발 산출물 또는 캐시가 어떤 경로로 이전 CSS를 계속 제공하게 됐는지는 확인하지 못했다.

## 해결 절차

1. 개발 서버를 실행한 터미널에서 `Ctrl+C`로 서버를 종료한다.
2. 저장소 루트의 PowerShell에서 아래 명령을 순서대로 실행한다.

   ```powershell
   Rename-Item -LiteralPath '.next/dev' -NewName ('dev-backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
   pnpm.cmd dev
   ```

   첫 명령은 기존 개발 산출물과 캐시가 담긴 폴더의 이름에 실행 날짜와 시각을 붙여 백업한다. 두 번째 명령은 개발 서버를 시작한다. Next.js는 새 `.next/dev` 폴더에 현재 소스를 기준으로 개발 산출물을 생성한다.

3. 터미널에 표시된 `Local` 주소를 Chrome에서 열고 `Ctrl+Shift+R`로 새로고침한다.
4. Windows 다크 모드를 유지한 상태에서 Chrome 개발자 도구의 **Elements → body → Computed**를 열고 `background-color`가 `rgb(243, 242, 237)`인지 확인한다. 이 값은 `#F3F2ED`와 같다.

새로 생성한 CSS에는 현재 배경색이 반영되고 이전 다크 모드 덮어쓰기 규칙이 사라진다. 따라서 시스템 테마와 관계없이 같은 배경색이 표시된다.

## 프로젝트 (2~3개)

### 모아 (Moa) — 파이널 프로젝트

- 한 줄 설명: 활동 지역을 기준으로 계모임·소모임을 찾고, 모임 운영과 회비·공동자금 관리를 한곳에서 할 수 있는 지역 커뮤니티 서비스입니다.
- 기간 / 인원: 2026.10.01.~2026.11.13. / 3명
- 사용 기술: Java 17, Spring Boot, MyBatis, MySQL, React, WebSocket, STOMP, 토스페이먼츠 가상계좌 발급 API
- 내가 맡은 것:
  - 팀장으로 개발 일정과 이슈를 관리하고 팀원이 개발한 기능을 통합했습니다.
  - 계모임·소모임 운영 기능을 개발하고, 계모임의 계원 관리, 회비 납부 관리, 공동자금 관리, 수령 순번 추천 및 지정 기능을 구현했습니다.
  - 프로젝트 규모에 맞춰 토스페이먼츠 API로 가상계좌를 발급하고, 공동자금의 입출금 내역은 MySQL에 저장해 조회할 수 있도록 구현했습니다.
  - 계모임별 채팅방을 만들고 WebSocket과 STOMP를 이용해 메시지를 실시간으로 주고받도록 구현했습니다.
- 링크(GitHub): https://github.com/siiiha/final_project_moa

### 쉽코딩 (EasyCoding) — 세미 프로젝트

- 한 줄 설명: 객관식·빈칸형 개발 문제와 오답 풀이를 제공하고, 학습 기록과 통계로 꾸준한 학습을 돕는 서비스입니다.
- 기간 / 인원: 2026.07.15.~2026.08.14. / 3명
- 사용 기술: Java, Spring Boot, Spring MVC, MyBatis, MySQL, JSP, HTML, CSS, JavaScript, Ajax, JWT
- 내가 맡은 것:
  - 커뮤니티 게시글에 이미지를 첨부할 수 있도록 이미지 업로드 기능을 구현했습니다.
  - JWT 기반 인증이 반복되는 횟수와 인증 처리 시간을 줄여 조회 응답 속도를 개선했습니다.
  - 형상 관리와 회의록 작성을 맡았습니다.
- 링크(GitHub): https://github.com/Kim-ilhyeon/semi_project-easycoding
